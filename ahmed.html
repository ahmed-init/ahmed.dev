projects

Things I've built

Simple RAG system

I built a retrieval-augmented generation pipeline from scratch to actually understand how RAG works instead of just using an API that does it for me. It chunks documents, generates embeddings, stores them, and retrieves the most relevant context before an LLM answers a question with it. This was my first hands-on project in the GenAI space, and it's what got me interested in agentic systems in the first place.

RAG Embeddings LLM Python
Coding & debugging agent

I built an agent that can read through code, find bugs, and suggest or apply fixes on its own, instead of me just prompting a model line by line. It's my introduction to agentic AI — the difference between a model that talks and a model that's given tools and a goal and figures out the steps itself.

Agentic AI LLM Python
ZAIN — full-stack e-commerce platform

I built ZAIN to practice putting together a complete system end to end, not just a frontend demo. It handles product listings, a shopping cart, and order management, with a Spring Boot backend exposing REST APIs and MongoDB storing the data. I'm currently getting it ready for deployment.

React.js Tailwind CSS Spring Boot MongoDB
Brand Edge

I built the website for Brand Edge, a LinkedIn management service, starting from Figma designs that I converted into pixel-perfect React components. Since the project didn't need a full backend, I used Google Sheets as the data store, connected through Google Apps Script, so every form submission lands straight into a spreadsheet. I also tried adding Cashfree for payments, but the account was never approved, so right now the site runs on lead capture only, not live payments.

React.js Figma Google Sheets Apps Script
Chat-Bot

A chatbot with a React frontend where I handled all the message logic and conversation flow myself in JavaScript, including state management and keeping track of message history, rather than relying on a chat library to do it for me.

React.js JavaScript
Employee Leave Management System

I'm building a full-stack system for handling employee leave requests and approvals, with role-based access for employees versus admins, JWT authentication, and real-time status updates. The backend runs on FastAPI with MySQL, and I'm currently adding an AI layer using Ollama that gives managers leave-approval recommendations based on an employee's history.

React.js FastAPI JWT Auth MySQL Ollama
