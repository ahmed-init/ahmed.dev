Simple RAG system

I built a retrieval-augmented generation pipeline from scratch to actually understand how RAG works instead of just using an API that does it for me. It chunks documents, generates embeddings, stores them, and retrieves the most relevant context before an LLM answers a question with it. This was my first hands-on project in the GenAI space, and it's what got me interested in agentic systems in the first place.
